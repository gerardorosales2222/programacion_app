# Desafío Flutter Botones

Una aplicación Flutter que demuestra el uso de botones y widgets interactivos.

## Requisitos

- Flutter SDK
- Dart SDK
- Editor de código (VS Code, Android Studio, etc.)

## Instalación

```bash
flutter pub get
```

## Ejecución

```bash
flutter run
```

## Estructura del Proyecto

```
lib/
├── main.dart           # Punto de entrada de la aplicación
└── ...
```

## Características

- Interfaz interactiva con botones
- Respuesta a eventos de usuario
- Diseño responsivo
